## 🧭 Ce que je fais

Je pars du terrain : **audit des process → besoins cachés → solution automatisée (ou pas)**.
15 ans d'opérationnel (export B2B, yield management hôtelier, production touristique), puis la data et l'IA générative pour outiller ce que je connaissais à la main.

| | |
|---|---|
| 🔍 **Audit & cadrage** | Cartographie des process, identification des irritants, priorisation ROI, cahier des charges |
| ⚙️ **Automatisation & IA** | Workflows n8n / Make, agents IA, apps no-code et vibe-codées, intégrations API |
| 🛡️ **Gouvernance & run** | Travail au ticket, SLA, RGPD, RLS / sécurité des données, recette et documentation |
| 📊 **Data & décision** | Analyse, ML appliqué, dashboards Tableau / Power BI / Streamlit, restitution COPIL |
